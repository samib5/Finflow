# Finflow

Finflow is a personal finance management project built with Python.

The goal is to progressively build a real-world application for tracking income and expenses while learning software development best practices.

## Goals

* Learn Python by building a real project
* Practice software development best practices
* Use Git and GitHub regularly
* Build and improve features progressively
* Write and maintain tests
* Eventually turn Finflow into a production-ready backend application

## Technologies

* Python 3.12
* Git
* GitHub

## Project Status

Finflow is currently a small Python program. This is the first version of the project and will be progressively expanded as new features are added.
